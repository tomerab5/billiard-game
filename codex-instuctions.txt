Upgrade ball–ball collisions to include spin + friction impulse (Coulomb).
Requirements:

In physics, represent each ball with linear velocity v (2D) and angular velocity w (3D). If w already exists, use it.

For a ball–ball collision, compute contact normal n (in table plane), contact offsets r1 = R*n, r2 = -R*n (3D vectors with z=0).

Compute relative velocity at contact: vRel = (v2 + w2×r2) - (v1 + w1×r1).

Compute normal impulse Jn using coefficient of restitution e_bb (keep current value).

Compute tangential impulse Jt that opposes tangential relative motion, clamped by |Jt| <= mu_bb * Jn.

If tangential relative speed is near zero, skip Jt.

Apply impulses to both balls:

v += ± J/m

w += I^{-1} (r × (±J)) with I = 2/5 m R^2

Keep determinism and keep JavaFX out of physics.

With initial side spin on cue ball, after collision: target ball gets some sideways component OR cue ball loses some spin (assert non-zero transfer).
