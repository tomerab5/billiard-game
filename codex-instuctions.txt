Implement “2.5D realistic ball shading” on the existing Canvas renderer.
Requirements:

Create a renderer helper (e.g., BallRenderer) or a drawBall(GraphicsContext gc, BallState b) method.

Add global light direction L in screen space (e.g., from top-left), and constants:

AMBIENT = 0.25, DIFFUSE = 0.75, SPECULAR = 0.6, SPECULAR_SIZE = 0.35*R (tunable).

Render passes per ball:

Contact shadow: draw a soft ellipse under the ball using a radial gradient; offset slightly opposite the light direction.

Base sphere shading: fill the ball circle using a radial gradient that’s brighter near the light-facing side and darker at rim.

Specular highlight: draw a small bright radial gradient spot near the light-facing side (not rotating with spin).

Spin decals: use the existing quaternion-rotated marker points; draw them as small colored dots/patches, only when rotated point has z>0; scale alpha by z.

Add toggle keys:

V toggles decals/markers

H toggles highlight+shading (for debugging)

Keep physics unchanged; tests should remain unchanged.
