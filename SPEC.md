# MVP Specification

## Scope

- Top-down 2D billiards simulation.
- Java 17 runtime.
- JavaFX 21.0.10 rendering.
- Single window with a billiards table, 6 pockets, and 1 cue ball.
- Continuous redraw loop for rendering updates.

## Out of Scope (Initial MVP)

- Ball spin / english.
- Advanced physics (friction curves, cushion response tuning, spin transfer).
- Cue controls, aiming UI, scoring, and game rules.
- Multiplayer and networking.
