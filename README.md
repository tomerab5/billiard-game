# 2D Billiards Simulator (JavaFX)

This project is a Java 17 + JavaFX 21.0.10 MVP for a top-down 2D billiards simulator.

## Prerequisites

- Java 17 installed and available on PATH

## Run

Use Maven Wrapper so a local Maven installation is not required:

```powershell
.\mvnw.cmd javafx:run
```

## Test

Run unit tests with:

```powershell
.\mvnw.cmd test
```
